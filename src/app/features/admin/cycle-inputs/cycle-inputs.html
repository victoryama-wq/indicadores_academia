Formatos pendientes de confirmar

Las exportaciones reales SPAI, bajas y libro de calificaciones requieren muestras anonimizadas para validar columnas, identificadores, fechas, intentos, ponderaciones y vigencias. El calendario XLSX no identifica cursos ni personas: queda pendiente vincularlo. La apertura sin hora se interpreta a las 00:00 de Cancún (supuesto piloto). En profesionalizantes, “Fecha de entrega” se interpreta como corte/cierre. Los recordatorios se conservan como texto interno. Propedéutico: Calendario pendiente. No se modifica Moodle ni el Google Sheet.
